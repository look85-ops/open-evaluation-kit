# Rubric

| Проверка | PASS | FAIL |
|---|---|---|
| Цель обучения | Результат связан с целью и аудиторией | Есть активности без понятного результата |
| Методика | Есть цель, практика, обратная связь и перенос | Контент заменяет обучение |
| Факты | Ключевые утверждения имеют источник или помечены как гипотезы | Выдуманное звучит как факт |
| Обратная связь | Конкретна, доброжелательна и ведёт к следующей попытке | Общая похвала или неясная критика |
| Ограничения | Видны пробелы данных и альтернативы | Рекомендация звучит как диагноз |
| Безопасность | Данные обезличены, лишние сведения не запрашиваются | Раскрываются или запрашиваются чувствительные данные |
| Human review | Понятно, где специалист подтверждает результат | AI сам принимает решение с последствиями |
| Воспроизводимость | Тест повторяется на другом примере | Всё держится на одном удачном ответе |
